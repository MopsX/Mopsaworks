Interfaces work better when they preserve **intent**, not just a trail of pixel-level decisions.

Imagine asking a collaborator to move a button twenty pixels to the right. The instruction is precise, but it hides the reason behind the change. Was the button hard to notice? Did it need a larger touch target? Was the layout unbalanced? A future editor—or an AI assistant—can preserve the number and still lose the idea.

## Describe the outcome

A stronger brief explains what the interface should accomplish:

- Make the primary action easy to find.
- Let visitors choose a suggested option or write their own.
- Keep the layout calm when content grows.

These goals leave room for the right implementation. A design system can choose appropriate spacing, a combobox can replace a basic select when custom input is required, and accessibility rules can remain part of the solution.

## Treat the interface as a living system

Websites are never truly finished. Products change, content expands, and new devices alter the constraints. A collection of one-off fixes becomes fragile because every decision depends on the exact state that existed when it was made.

Intent is more durable. It gives future changes a standard to evaluate against: does this version still make the important action clear? Does it still support a long headline? Does it still work with a keyboard?

> The valuable artifact is not only the final screen. It is the reasoning that makes the screen useful.

## Make taste part of the loop

Not every preference can be reduced to a rule. Sometimes one direction simply feels more appropriate. A good AI-assisted workflow should offer several coherent options, record the chosen direction, and ask again when later changes challenge that preference.

This turns taste into feedback instead of pretending it does not exist. It also makes experimentation cheaper: teams can compare multiple approaches before investing heavily in one.

## From control to guidance

Direct manipulation will remain valuable, especially for careful finishing work. But the starting point can shift from drawing every rectangle to explaining the purpose, audience, and constraints.

That shift is less about giving up control and more about working at the right level. Humans define what matters. Tools help translate those priorities into consistent, accessible, adaptable interfaces.
